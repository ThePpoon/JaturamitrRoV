# สเปกกราฟิก

ขนาดจริงที่ระบบใช้แสดงผล วัดจาก CSS บนผืนผ้าใบ **1920 × 1080** (OBS ตั้ง browser source เท่านี้ scale = 1)

---

## รูปฮีโร่

**ที่อยู่ไฟล์:** `public/heroes/<id>.png` — `id` ต้องตรงกับใน `src/data/heroes.json`
**นามสกุลอะไรก็ได้** (`.png` `.webp` `.jpg` `.avif`) hub หาให้เองผ่าน `/api/hero-image/:id`

### ขนาดที่แสดงจริง

| จุดที่ใช้ | ขนาดบนจอ | ไฟล์ |
|---|---|---|
| ช่องฮีโร่ที่ถูกเลือก (การ์ดใหญ่) | **140 × 233** ← ใหญ่สุด ใช้ตัวนี้เป็นเกณฑ์ | overlay `banpick` |
| ช่องฮีโร่ที่ถูกแบน | **74 × 66** | overlay `banpick` |
| ตารางเลือกฮีโร่ในหน้าคุม | 46 × 46 | control panel |
| ช่องดราฟต์ในหน้าคุม | 34 × 34 | control panel |

> การ์ด pick ใช้ `object-fit: cover` บนกรอบแนวตั้ง 3:4 — รูปจัตุรัสจะถูกครอบตัดซ้ายขวา
> ตัวละครส่วนใหญ่อยู่กลางภาพอยู่แล้วจึงไม่มีปัญหา แต่ถ้าตัวไหนโดนตัดหน้าให้หารูปแนวตั้งมาแทน

### ข้อกำหนดไฟล์

| | |
|---|---|
| สัดส่วน | **สี่เหลี่ยมจัตุรัส 1:1** |
| การครอบ | `object-fit: cover` — ไฟล์ที่ไม่ใช่จัตุรัสจะถูก **ครอบตัดจากกึ่งกลาง** |
| ขนาดขั้นต่ำ | **256 × 256** |
| ขนาดที่แนะนำ | **512 × 512** |
| พื้นหลัง | ทึบหรือใสก็ได้ (มุมถูกมนด้วย `border-radius` อยู่แล้ว) |

> ทำไมต้อง 256px ทั้งที่แสดงแค่ 44px — เผื่อไว้สำหรับกราฟิกที่ใหญ่ขึ้นในอนาคต
> (เช่นฉากโชว์ทีมหรือหน้า ban/pick เต็มจอ) และเผื่อกรณีอัปสเกลผืนผ้าใบเป็น 4K
> ไฟล์ 512px ใหญ่แค่หลักสิบ KB ไม่กระทบประสิทธิภาพ

### สถานะไฟล์ปัจจุบัน

ตรวจด้วย `node scripts/check-hero-images.mjs --min 256`

รูปที่ดึงจาก API ทางการ **ความละเอียดไม่สม่ำเสมอ** — ผ่านเกณฑ์ 256px แค่ 29 จาก 110 ตัว

| ความละเอียด | จำนวน | ใช้งานได้ไหม |
|---|---|---|
| 500–1080px | 29 ตัว | ดี |
| 120 × 120 | 8 ตัว | พอใช้ที่ 44px |
| **100 × 100** | **71 ตัว** | พอดีตัวที่ 44px แต่ไม่เหลือให้ขยาย |
| 261 × 255 (`tachi`) | 1 ตัว | ไม่จัตุรัส จะโดนครอบตัด |

**ที่ 44px บนจอ ไฟล์ 100px ยังคมอยู่** (เหลือ 2.3 เท่า) จึงใช้ออกอากาศได้เลย
แต่ถ้าจะทำกราฟิกที่โชว์รูปฮีโร่ใหญ่กว่านี้ ต้องหารูปความละเอียดสูงมาแทน 71 ตัวนั้น

เอาไฟล์ใหม่มาวางทับได้เลย ตั้งชื่อตาม `id` — หรือใช้
`node scripts/import-heroes.mjs <โฟลเดอร์>` ให้จับคู่ชื่อไฟล์ให้อัตโนมัติ

## แถบสกอร์ — ต้องวางทับวิดีโอ `animation/Score2.mp4`

พื้นหลังของแถบสกอร์ **ไม่ได้วาดด้วย CSS** แต่เป็นวิดีโอ `animation/Score2.mp4` (1920 × 1080 · 13.95 วิ · พื้นเขียว)
ที่วางเป็น media source ใน OBS overlay มีหน้าที่วางแค่ตัวหนังสือลงในช่องว่างที่วิดีโอเว้นไว้

### ลำดับชั้นใน OBS (บนลงล่าง)

| ลำดับ | source | หมายเหตุ |
|---|---|---|
| 1 (บนสุด) | Browser Source `/overlay/scoreboard` | **1920 × 1080** พื้นโปร่งใส |
| 2 | Media Source `animation/Score2.mp4` | ติ๊ก Loop · ใส่ Chroma Key เอาพื้นเขียวออก |
| 3 | ภาพเกม | |

> ตรวจ/แก้อัตโนมัติด้วย `npm run fix:obs-size` (ดู `docs/obs-setup.md` หัวข้อ 10)

**โลโก้ทีมแสดงเฉพาะทีมที่เลือกไฟล์โลโก้ไว้** ในหน้าคุม → แท็บสกอร์บอร์ด → การ์ดทีม → ช่อง "โลโก้"
ทีมที่ไม่ได้เลือกจะไม่แสดงอะไรเลยตรงนั้น (ไม่ fallback เป็นตัวย่อ เพราะซ้ำกับชื่อย่อตัวใหญ่ที่อยู่ข้าง ๆ)

ตำแหน่งตั้งต้นอยู่ระหว่างชื่อย่อกับข้อความกลางแถบ (กึ่งกลาง x **745** / **1175** สมมาตรกัน)
ซึ่งเป็นช่องว่างที่กว้างที่สุดที่เหลืออยู่บนแถบ

### ตัวแปรของแต่ละชิ้น — ขยับแยกกันได้ทุกตัว

ทุกชิ้นบนแถบเป็น element พี่น้องกัน **ไม่มีกล่องครอบ** และมีตัวแปรของตัวเองครบชุด
`x` = ขอบซ้าย · `y` = ขอบบนของกล่อง · `w` = ความกว้าง · `size` = ขนาดตัวอักษร
ขยับทีละชิ้นได้อิสระทั้งซ้ายขวาและขึ้นลง ไม่มีชิ้นไหนลากชิ้นอื่นตามไป

| ชิ้น | ซ้าย/ขวา | **ขึ้น/ลง** | ความกว้าง | ขนาดตัวอักษร |
|---|---|---|---|---|
| ชื่อรอบ | `--sb-label-x` | `--sb-label-y` | `--sb-label-w` | `--sb-label-size` |
| สกอร์ทีม A | `--sb-score-left-x` | `--sb-score-left-y` | `--sb-score-w` | `--sb-score-size` |
| สกอร์ทีม B | `--sb-score-right-x` | `--sb-score-right-y` | เหมือนกัน | เหมือนกัน |
| โลโก้ทีม A | `--sb-logo-left-x` | `--sb-logo-left-y` | `--sb-logo-size` (จัตุรัส) | — |
| โลโก้ทีม B | `--sb-logo-right-x` | `--sb-logo-right-y` | เหมือนกัน | — |
| ชื่อย่อทีม A | `--sb-abbr-left-x` | `--sb-abbr-left-y` | `--sb-abbr-w` | `--sb-abbr-size` |
| ชื่อย่อทีม B | `--sb-abbr-right-x` | `--sb-abbr-right-y` | เหมือนกัน | เหมือนกัน |
| แมตช์/เกม | `--sb-center-x` | `--sb-center-y` | `--sb-center-w` | `--sb-center-size` |
| ชื่อเต็มทีม A | `--sb-plate-left-x` | `--sb-plate-left-y` | `--sb-plate-w` | `--sb-plate-size` |
| ชื่อเต็มทีม B | `--sb-plate-right-x` | `--sb-plate-right-y` | เหมือนกัน | เหมือนกัน |

**ค่า `y` อ่านยังไง**

| ชิ้น | ความหมายของ y |
|---|---|
| ทุกชิ้นที่อยู่ในแถบสีม่วง | **0 = กึ่งกลางแถบพอดี** · บวก = เลื่อนลง · ลบ = เลื่อนขึ้น |
| โลโก้ทีม | ขอบบนของโลโก้ — กล่องเท่าขนาดโลโก้พอดี ไม่ได้สูงเท่าแถบเหมือนชิ้นอื่น<br>กึ่งกลางแถบ = `(--sb-bar-h − --sb-logo-size) / 2` = **12px** เมื่อโลโก้ 56px |
| ชื่อเต็มทีม (แผ่นขาว) | ขอบบนของแผ่นขาวจริง ๆ — ค่าตั้งต้น **81px** ตรงกับวิดีโอ |

ตัวแปรเพิ่มเติม: `--sb-bar-h` (ความสูงกล่องที่ใช้จัดกึ่งกลาง = 80px)
· `--sb-center-gap` (ระยะห่างสองบรรทัดกลาง) · `--sb-plate-h` · `--sb-plate-inset`

> ทำไมต้องแยกชื่อย่อกับชื่อเต็ม — ชื่อย่ออยู่บนลายกราฟิกในแถบ จัดตำแหน่งตามความสวยงามได้
> แต่ชื่อเต็มต้องล็อกอยู่กับแผ่นขาวที่วิดีโอวาดไว้ ถ้าผูกไว้ด้วยกันแล้วเลื่อนชื่อย่อ
> ชื่อเต็มจะหลุดออกนอกแผ่นขาวทันที

### ถ้าตัดต่อวิดีโอใหม่แล้วช่องขยับ

แก้ตัวแปร `--sb-*` ใน `src/overlay/overlay.css` ที่บล็อก `.sb-bar` ชุดเดียวพอ ไม่ต้องไล่แก้ทีละกฎ

> ชื่อคลาสในแถบสกอร์ต้องขึ้นต้นด้วย `sb-` เสมอ — `control.css` ถูก import แบบ global ใน `main.tsx`
> ชื่อกลาง ๆ อย่าง `.slot` จะไปชนกับช่องดราฟต์ในหน้าคุม แล้วได้กล่องพื้นเข้มมาทับแถบ

### ขนาดตัวอักษรบนแถบ

| ชิ้น | ขนาด | ฟอนต์ |
|---|---|---|
| ชื่อย่อทีม | **60px** ขาว (`--sb-abbr-size`) | Barlow Condensed 700 |
| ตัวเลขสกอร์ | **58px** ขาว | Barlow Condensed 700 |
| ชื่อรอบ | **34px** (ย่อเองถึง 18px ถ้าชื่อยาว เช่น "QUARTER FINALS") | Barlow Condensed 700 |
| `MATCH n - BOm` / `GAME g` | **32px** สองบรรทัด | Barlow Condensed 700 |
| ชื่อเต็มทีมบนแผ่นขาว | **15px** (`--sb-plate-size` · ย่อเองถึง 10px ถ้าชื่อยาวเกินแผ่น) | IBM Plex Sans Thai 600 |

ชื่อเต็มบนแผ่นขาวเอา `prefix` มาต่อกับ `name` เป็นบรรทัดเดียว
("เบญจมราชูทิศ" + "จันทบุรี" → "เบญจมราชูทิศ จันทบุรี")

### ตั้งค่าจากหน้าคุม

แท็บ **สกอร์บอร์ด** → การ์ด "แมตช์"

| ช่อง | ไปโผล่ที่ |
|---|---|
| ชื่อรอบ | ถัดจากโลโก้รายการ — เว้นว่างได้ ถ้าว่างจะไม่แสดงอะไรเลย |
| แมตช์ที่ | `MATCH n` กลางแถบ |
| เกมที่ | `GAME g` กลางแถบ |
| ชื่อย่อ (การ์ดทีม) | ตัวใหญ่กลางแถบสีม่วง |
| บรรทัดบน + ชื่อทีม | ต่อกันเป็นชื่อเต็มบนแผ่นขาว |

`BOm` มาจาก `bestOf` ซึ่งยังตั้งค่าจากหน้าคุมไม่ได้ (ค่าคงที่ 3) แก้ที่ `defaultState()` ใน `server/state.ts`

## หน้า Ban / Pick — ต้องวางทับกราฟิก overlay

ทำงานแบบเดียวกับแถบสกอร์: กราฟิกที่ออกแบบไว้แล้ววางเป็น source อยู่ **ใต้** browser source
ส่วน overlay โปร่งใสสนิท มีหน้าที่เติมของลงในช่องที่กราฟิกเว้นไว้เท่านั้น

### กราฟิกวาดให้แล้ว — overlay ห้ามวาดซ้ำ

ป้าย `BAN` สองข้าง · โลโก้กับชื่อรายการตรงกลาง · คำว่า `VS` · กรอบช่องแบนและช่องเลือกทุกช่อง
· แถบสีชมพูใต้ช่องเลือก · พื้นหลังทั้งหมด

### overlay เติมอะไรลงไปบ้าง

| ชิ้น | มาจาก | ตั้งค่าที่ |
|---|---|---|

### เอฟเฟกต์

จังหวะเลียนจากกราฟิกของลีกทางการ — ทุกอย่างเป็น CSS ล้วน ไม่มี JS ทำอนิเมชัน

| จังหวะ | เอฟเฟกต์ | ระยะ |

| ตัวที่ถูกแบน | ขีดทับลากออกจากกลางไปสองข้าง | 0.4 วิ (หน่วง 0.22) |

| สกอร์เปลี่ยน | เด้งจาก 1.55 เท่า + สว่างวาบ | 0.42 วิ |
| ลูกศรข้างนาฬิกา | ชี้ไปทางทีมที่ถึงตาเลือก ฝั่งที่ไม่ใช่ตาจะจาง | วนไม่หยุด |
| 5 วินาทีสุดท้าย | ตัวเลขเต้น (แทนการกะพริบทั้งก้อนแบบเดิม อ่านง่ายกว่าตอนถ่ายทอดสด) | วนไม่หยุด |

ปรับสีแสงของช่องที่ถึงตาเลือกได้ที่ `--bp-glow-in` (ชั้นใน สว่าง) และ `--bp-glow-out` (ชั้นนอก เข้ม)
ในบล็อก `.bp` — เก็บเป็นค่า `R G B` ล้วน ไม่มี `rgb()` ครอบ เพราะต้องเอาไปผสม alpha หลายชั้น
เขียนเป็น `rgb(var(--bp-glow-in) / 0.5)` ถ้าใส่ `rgb()` ไว้ในตัวแปรจะผสม alpha ไม่ได้

**ตัวที่สั่งให้เอฟเฟกต์เล่นซ้ำคือ `key` ใน `BanPick.tsx`** ไม่ใช่ CSS —
`key={id}` ทำให้ React mount element ใหม่ทุกครั้งที่เปลี่ยนฮีโร่ animation จึงเริ่มใหม่
ถ้าเปลี่ยน key กลับไปเป็น index เมื่อไหร่ เอฟเฟกต์จะเล่นแค่ตัวแรกแล้วเงียบไปเลย

ชื่อผู้เล่นเป็นข้อยกเว้น ใช้ `transition` ไม่ใช่ `animation` — เพราะคนคุมพิมพ์ทีละตัวอักษร
ถ้าผูกกับ key จะกระตุกใหม่ทุกตัวที่พิมพ์

ระยะเวลาตั้งใจให้สั้นกว่าจังหวะกดของคนคุม จะได้ไม่หน่วงตอนดราฟต์รัว ๆ

### ช่องที่กำลังรอกรอก

ทำเป็น `inset box-shadow` สีเหลือง ไม่ใช่ `border` — เพราะกรอบจริงเป็นของกราฟิก
ถ้าวาดขอบทับจะเบิ้ลกับกรอบเดิมจนดูหนา

| ป้ายหัวแถว | เช่น `MATCH 3` · `NEXT MATCH` — ตัดมุมสองข้างให้เข้าชุดกับกราฟิกอื่นของรายการ |
| เนื้อหา แบบ `versus` | ตราซ้าย + กล่องกลาง (`3 - 4` หรือ `VS`) + ตราขวา |
| เนื้อหา แบบ `text` | ข้อความเดียวตัวใหญ่ไล่สีทอง เช่น `SHOWMATCH` |
| เวลา | บรรทัดเล็กใต้กล่องกลาง เช่น `10:30 AM` |

**แถวที่ไม่ได้กรอกอะไรเลยจะไม่ถูกเรนเดอร์** — วันไหนมี 2 แมตช์ก็กรอกแค่ 2 แถว ไม่ต้องปิดอะไรเพิ่ม
(แถวที่มีแค่เวลาอย่างเดียวยังนับว่าใช้อยู่)
