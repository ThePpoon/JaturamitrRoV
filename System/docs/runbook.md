## 1 วันก่อนงาน

- [ ] วัดความเร็ว **upload จริง ณ สถานที่จัดงาน** (ไม่ใช่ที่บ้าน/ออฟฟิศ) — ต้องได้ ≥ 2 เท่าของ bitrate
- [ ] ทดสอบไลฟ์เข้า Facebook แบบ **Only me** อย่างน้อย 10 นาที ดูว่า dropped frames เป็น 0%
- [ ] ตรวจว่า persistent stream key ยังใช้ได้
- [ ] ใส่โลโก้ทีมทั้งหมดใน `public/teams/` และโลโก้สปอนเซอร์ใน `public/sponsors/`
- [ ] อัปเดตรายชื่อทีมใน `src/data/teams.json`
- [ ] รัน `npm run heroes:fetch` เพื่อดึงรายชื่อฮีโร่และรูปล่าสุดจาก API ทางการ (ROV ออกฮีโร่ใหม่บ่อย)
- [ ] รัน `npm run heroes` ยืนยันว่ารูปครบ — ตัวที่ขาดจะขึ้นเป็นตัวย่อ ใช้งานได้แต่ไม่สวย
- [ ] ซ้อม BO3 เต็มรูปแบบหนึ่งแมตช์
- [ ] ทดสอบ hotkey F1–F8 และ F9 ใน OBS ว่าใช้ได้จริง
- [ ] เตรียมของสำรอง: capture card, สาย HDMI, สาย USB, แบตสำรอง/UPS

## ระหว่างรายการ

### ลำดับฉากมาตรฐานของหนึ่งแมตช์ BO3

```
F1 Starting Soon  →  F2 Casters Desk  →  F3 Ban Pick  →  F4 Live Game
                                              ↑              ↓
                                         (เกมถัดไป)  ←  F6 Break
                                                            ↓
                                          F7 Results  →  F8 Ending
```

### สิ่งที่ต้องคอยดูตลอด

| ตัวเลข | ปกติ | ถ้าผิดปกติให้ทำ |
|---|---|---|
| **เฟรมหลุด** | `0.00%` | เกิน `1%` → ลด bitrate ทันที หรือสลับเป็น 720p |
| CPU | < 70% | เกิน → ปิดโปรแกรมอื่น หรือเปลี่ยนไปใช้ hardware encoder |
| FPS | 60 | ตกค้าง → ตรวจ capture card และ GPU |
| bitrate | ใกล้ค่าที่ตั้งไว้ | ตกฮวบ → เน็ตมีปัญหา |

### งานประจำในแต่ละเกม

1. **ก่อนแบน-พิค** — ไปแท็บ Ban/Pick กด "ล้างกระดาน" แล้วสลับฉาก F3
2. **ระหว่างแบน-พิค** — คลิกฮีโร่ตามที่เห็นบนจอ ระบบเลื่อนช่องให้เอง
3. **เข้าเกม** — สลับฉาก F4
4. **จบเกม** — ไปแท็บสกอร์บอร์ด กด `+` ให้ทีมที่ชนะ แล้วเพิ่มเลขเกม → สลับฉาก F6
5. **จบแมตช์** — เลือกช่วง "สรุปผล" ในแท็บ Overlay → สลับฉาก F7

## เมื่อเกิดปัญหา

| อาการ | ทำอย่างไร |
|---|---|
| **หน้าคุมค้าง / เปิดไม่ได้** | ใช้ hotkey `F1`–`F8` ใน OBS คุมฉากต่อไปก่อน แล้วค่อยรีสตาร์ท `npm run dev` — สกอร์ไม่หายเพราะเก็บไว้ใน `state.json` |
| **overlay เป็นหน้าขาว** | คลิกขวาที่ browser source > `Refresh` — ถ้ายังไม่หาย แปลว่า hub ดับ ให้รัน `npm run dev` ใหม่ |
| **หน้าคุมขึ้นแถบแดง "ต่อกับ OBS ไม่ได้"** | ตรวจว่า OBS เปิดอยู่และ WebSocket Server เปิด แล้วกดปุ่ม "ลองใหม่" |
| **ภาพเกมดำ** | ดับเบิลคลิก `CAM - Capture Card` แล้วเลือก device ใหม่ · ถ้าไม่ขึ้นให้ถอดเสียบ USB |
| **เฟรมหลุดพุ่ง** | ลด bitrate ลง 30% ทันทีระหว่างไลฟ์ได้เลย — ภาพเบลอลงดีกว่าภาพค้าง |
| **ไลฟ์หลุดจาก Facebook** | อย่าหยุดอัด กด "เริ่มไลฟ์" ใหม่ Facebook จะต่อสตรีมเดิมให้ถ้าใช้ persistent key |
| **เสียงผู้บรรยายไม่ออก** | ตรวจ `Settings > Audio > Global Audio Devices` และดูว่าไม่ได้กด mute ไว้ใน Audio Mixer |
| **เสียงไม่ตรงภาพ** | ปรับ `Advanced Audio Properties > Sync Offset` ระหว่างไลฟ์ได้เลย |
