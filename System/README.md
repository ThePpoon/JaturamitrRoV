# Jaturamitr ROV — ระบบสตรีมการแข่งขัน

ชุดเครื่องมือถ่ายทอดสดการแข่งขัน ROV รูปแบบ BO3 ออก Facebook Live
ประกอบด้วย OBS scene collection สำเร็จรูป, หน้าคุมบนเว็บ และ overlay ที่อัปเดตแบบ real-time

---

## เริ่มใช้งาน

### ติดตั้งบนเครื่องใหม่ — ดับเบิลคลิก `setup.bat`

ไฟล์เดียวจบ: ตรวจและติดตั้ง Node.js ถ้ายังไม่มี · `npm install` · สร้าง `.env`
พร้อมถามรหัส obs-websocket · โหลดรูปฮีโร่ · ตรวจว่ามี OBS หรือยัง

**คัดลอกโฟลเดอร์นี้ไปเครื่องใหม่ได้เลย แต่อย่าเอา `node_modules` ไปด้วย** —
มีไฟล์ที่คอมไพล์มาเฉพาะเครื่อง `setup.bat` จะติดตั้งใหม่ให้เอง

`setup.bat` จะไม่แตะไฟล์ `.env` เดิมถ้ามีอยู่แล้ว

### ติดตั้งเอง

```bash
npm install
cp .env.example .env          # แล้วใส่รหัส obs-websocket
npm run dev
```

เปิด **`http://localhost:3000/control`**

terminal จะพิมพ์ URL สำหรับเปิดจากแท็บเล็ตในวง LAN เดียวกันให้ด้วย

จากนั้นทำตาม [`docs/obs-setup.md`](docs/obs-setup.md) เพื่อตั้งค่า OBS
และใช้ [`docs/runbook.md`](docs/runbook.md) เป็น checklist วันแข่ง

## สถาปัตยกรรม

```
                         ┌──────────────────────────┐
   แท็บเล็ต/มือถือ ─────►│                          │
   (หน้าคุม)             │   Hub Server (Node)      │──ws──► OBS Studio
                         │   :3000                  │       (obs-websocket :4455)
   OBS Browser Source ──►│   • MatchState           │
   (overlay)             │   • state.json           │
                         └──────────────────────────┘
```

**hub server เป็นตัวเดียวที่คุยกับ OBS** ไม่ใช่เบราว์เซอร์ เพราะ obs-websocket v5 ใช้ SHA256
ตอน auth ซึ่งเบราว์เซอร์ทำได้เฉพาะใน secure context — ถ้าให้หน้าคุมบนแท็บเล็ตต่อ OBS ตรง
ผ่าน `http://192.168.x.x` จะ auth ไม่ผ่าน การวาง hub ไว้ตรงกลางแก้ปัญหานี้
พร้อมได้ผลพลอยได้คือ state อยู่ที่เดียว รีเฟรชหน้าคุมได้ไม่หาย และเปิดพร้อมกันหลายเครื่องได้

state ทุกก้อนถูกเขียนลง `state.json` แบบ atomic — hub ดับกลางรายการแล้วสกอร์ไม่หาย

## ชื่อทีม

ชื่อทีมแสดงสองบรรทัด — `prefix` เป็นบรรทัดเล็กด้านบน `name` เป็นบรรทัดใหญ่

```json
{
  "prefix": "เบญจมราชูทิศ",
  "name": "ราชบุรี",
  "short": "บ.ช.",
  "logo": "",
  "color": "#2962ff",
  "color2": "#ff4081"
}
```

ออกแบบมาสำหรับรายการที่ทุกทีมชื่อขึ้นต้นเหมือนกัน (อย่างจตุรมิตรเบญจมราชูทิศ)
ถ้าขึ้นชื่อเต็มทั้งสองฝั่ง คนดูจะแยกไม่ออกว่าใครเป็นใคร การเน้นส่วนที่ต่างกัน
เป็นตัวใหญ่ทำให้อ่านออกทันทีแม้ดูบนมือถือ

- **`prefix` เว้นว่างได้** — จะเหลือบรรทัดเดียวและจัดกึ่งกลางแนวตั้งเอง
- **`short`** ใช้ตอนไม่มีไฟล์โลโก้ และใช้กำกับแถวแบนในหน้า ban/pick
- ชื่อยาวเกินกรอบจะ **ย่อขนาดตัวอักษรลงเอง** (ไม่ตัดท้ายด้วย `…`) ดูที่ `FitText`
  ใน [src/overlay/Stage.tsx](src/overlay/Stage.tsx)

### สีประจำโรงเรียน

`color` เป็นสีหลัก `color2` เป็นสีรอง แสดงเป็น **แถบสองโทน** ข้างชื่อทีม
(สีหลักครึ่งบน สีรองครึ่งล่าง) เห็นได้ทั้งบนแถบสกอร์ หัวตาราง ban/pick และหน้าสรุปผล

`color` ตัวเดียวยังถูกใช้กับตัวเลขสกอร์ พื้นโลโก้ และจุดนับเกม จึงควรเป็นสีที่
**อ่านออกบนพื้นเข้ม** — สีเข้มจัดอย่างน้ำเงินกรมท่าจะจมไปกับพื้นแผงที่เป็นสีดำโปร่ง
ถ้าอยากได้สีจริงของโรงเรียนแบบเป๊ะ ๆ ให้ใส่ที่ `color2` แทนแล้วใช้เฉดที่สว่างกว่าเป็น `color`

ถ้าเว้น `color2` ว่าง แถบจะเป็นสีเดียวอัตโนมัติ

แก้ชื่อระหว่างไลฟ์ได้ตลอดจากแท็บ **สกอร์บอร์ด** ในหน้าคุม ไฟล์ `teams.json`
เป็นแค่ค่าตั้งต้นให้เลือกจาก dropdown

## รูปฮีโร่

### วิธีที่ง่ายที่สุด — ดึงจาก API ทางการของ Garena RoV ไทย

```bash
npm run heroes:fetch
```

คำสั่งเดียวจบ: ดึงรายชื่อฮีโร่จาก `rov.in.th/api/v2/getHeroList` โหลดรูป 500×500 ทั้งหมด
ลง `public/heroes/` แล้วอัปเดต `src/data/heroes.json` ให้ตรงกับเซิร์ฟเวอร์ไทย

```bash
npm run heroes:fetch -- --dry           # ดูก่อนว่าจะได้อะไร ไม่เขียนไฟล์
npm run heroes:fetch -- --images-only   # เอาแค่รูป ไม่แตะรายชื่อ
```

**รายชื่อจาก API ไม่ครบทั้งหมด** (ไม่มี Arthur, Batman, Kaine, Nova, Payna, Peura)
สคริปต์จึง **รวม** รายชื่อเดิมเข้ากับของทางการ ไม่ตัดตัวที่หายไปทิ้ง — เพราะถ้าวันแข่ง
มีทีมแบนตัวที่ไม่อยู่ในลิสต์ จะกรอกกระดานไม่ได้ ตัวที่ไม่มีรูปจะขึ้นเป็นตัวย่อแทน

รันซ้ำได้เรื่อย ๆ ก่อนแต่ละรายการเพื่ออัปเดตฮีโร่ใหม่ (ของเดิมสำรองไว้ที่ `heroes.json.bak`)

### ถ้ามีรูปจากแหล่งอื่นอยู่แล้ว

ไฟล์วางที่ `public/heroes/` ตั้งชื่อตาม `id` ใน `heroes.json`
**นามสกุลอะไรก็ได้** (`.png` `.webp` `.jpg` `.avif`) hub หาให้เองผ่าน `/api/hero-image/:id`

รูปที่โหลดมามักตั้งชื่อไม่ตรง เช่น `Tel'Annas.png` หรือ `128px-Lu Bu.webp`
ใช้สคริปต์จับคู่และเปลี่ยนชื่อให้:

```bash
npm run heroes                                    # ดูว่ามีรูปกี่ตัว ขาดตัวไหนบ้าง
node scripts/import-heroes.mjs <โฟลเดอร์> --dry   # ลองดูก่อนว่าจะจับคู่ยังไง
node scripts/import-heroes.mjs <โฟลเดอร์>         # คัดลอกเข้ามาจริง
```

สคริปต์อ่านโฟลเดอร์ย่อยด้วย และจะ **ไม่เดา** เมื่อไม่มั่นใจ — ไฟล์ที่จับคู่ไม่ได้หรือชนกัน
จะถูกรายงานออกมาให้เปลี่ยนชื่อเอง ดีกว่าขึ้นรูปผิดคนกลางไลฟ์

ขนาดที่แนะนำ: สี่เหลี่ยมจัตุรัส **256×256** ขึ้นไป (ระบบ crop ด้วย `object-fit: cover`)
ดูสเปกครบทุกชิ้นงานได้ที่ [docs/graphics-spec.md](docs/graphics-spec.md)

```bash
npm run heroes:check      # ตรวจว่ารูปไหนความละเอียดต่ำหรือไม่เป็นจัตุรัส
```

> รูปฮีโร่เป็นทรัพย์สินของ Garena/Tencent ดึงมาจากเว็บทางการเพื่อใช้ในรายการแข่ง
> ถ้ารายการมีสปอนเซอร์หรือหารายได้ ควรเช็คเงื่อนไขกับ Garena ก่อน
